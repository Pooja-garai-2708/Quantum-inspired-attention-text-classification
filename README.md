# Quantum-Inspired Attention Mechanism for Text Classification

## Overview

This project investigates a Quantum-Probability-Inspired Attention mechanism for binary sentiment classification. The study compares Standard Additive Attention, Quantum-Inspired Attention, and a Mean Pooling ablation model using the IMDb Large Movie Review Dataset.

The main objective is to determine whether a lightweight quantum-probability-inspired attention formulation can provide measurable benefits over conventional attention while using the same classical BiLSTM-based architecture.

## Problem Statement

Conventional attention mechanisms use Softmax-based weighting to determine the importance of different tokens in a sequence. This project investigates an alternative probability-inspired weighting mechanism based on squared transformed attention scores. The proposed approach is implemented entirely using classical neural-network operations and does not require quantum hardware or quantum circuits.

## Architecture

The common architecture used for the attention-based models is:

**Embedding → BiLSTM → Attention → Dense Classifier → Softmax**

The Mean Pooling ablation uses:

**Embedding → BiLSTM → Mean Pooling → Dense Classifier → Softmax**

## Dataset

The project uses the **IMDb Large Movie Review Dataset** for binary sentiment classification.

- Total reviews: 50,000
- Original training reviews: 25,000
- Original test reviews: 25,000
- Classes: Positive and Negative
- Class distribution: Balanced
- Vocabulary size: 20,000
- Maximum sequence length: 250
- Embedding dimension: 128

The original training set was divided into:

- Training: 22,500 reviews
- Validation: 2,500 reviews
- Testing: 25,000 reviews

The final split preserves the balanced positive and negative class distribution.

## Models

Three models were evaluated:

1. **Standard Additive Attention**
2. **Quantum-Inspired Attention**
3. **Mean Pooling Ablation**

### Standard Additive Attention

The baseline model uses conventional additive attention to assign Softmax-based weights to the contextual representations generated by the BiLSTM.

### Quantum-Inspired Attention

A probability-inspired attention mechanism that assigns importance to words using transformed attention scores. It is inspired by quantum probability but uses only classical neural-network operations.

### Mean Pooling

Mean Pooling is used as an ablation baseline to evaluate whether attention mechanisms provide an advantage over a simple aggregation of BiLSTM representations.

## Final Results

| **Model** | **Accuracy** | **Precision** | **Recall** | **F1** |
|---|---:|---:|---:|---:|
| Standard Additive Attention | **86.74%** | 84.80% | **89.53%** | **87.10%** |
| Quantum-Inspired Attention | 86.37% | **85.40%** | 87.74% | 86.56% |
| Mean Pooling | 86.35% | 84.81% | 88.56% | 86.65% |

## Key Findings

- Standard Additive Attention achieved the highest overall accuracy and F1-score.
- Standard Additive Attention also achieved the highest recall.
- Quantum-Inspired Attention achieved the highest precision.
- Quantum-Inspired Attention did not outperform Standard Additive Attention in overall classification performance.
- Mean Pooling produced competitive results with fewer parameters and lower inference time.
- The three models use the same basic BiLSTM-based classification framework, allowing a controlled comparison of the aggregation mechanism.

## Statistical Analysis

The Standard Additive Attention and Quantum-Inspired Attention predictions were further compared using McNemar's exact test and bootstrap confidence intervals.

- Accuracy difference: **-0.37 percentage points** for Quantum-Inspired Attention relative to Standard Attention.
- McNemar's exact test p-value: **0.009969**
- 95% bootstrap confidence interval for the accuracy difference: **[-0.0062, -0.0009]**
- Prediction agreement: **95.01%**

These results indicate a statistically significant difference between the paired predictions under the current experimental configuration, with Standard Additive Attention showing the better overall accuracy.

## Conclusion

Standard Additive Attention achieved the best overall performance with an accuracy of 86.74% and an F1-score of 87.10%. Quantum-Inspired Attention achieved the highest precision at 85.40%, but it did not outperform the Standard Attention baseline overall. Mean Pooling remained competitive while providing a simpler aggregation mechanism.

The results therefore do not demonstrate an overall performance advantage for the proposed Quantum-Inspired Attention mechanism under the current experimental configuration, but they provide a controlled evaluation of a lightweight quantum-probability-inspired attention formulation for text classification.
